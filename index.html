Why the field of ICT suits me:

I believe that I have chosen the right field because of my ability to understand and perform well in this field. I am able to keep up with my subjects, participate in class activities and get good grades in my tests. My passion for the field is now growing even stronger as I am able to grasp the concepts being taught, it is also feeding my imagination in what I am able to do and what I would like to do in the future.

Reasons why I like this field

  • Problem solving in programming is a fun activity for me
  • I feel very accomplished after finishing a difficult task
  • I am excited to learn more and be able to start creating software
  • Eventually I would like to create software solutions that could help someone

What I have learned in Computer Science Basics:

The computer science basics class is an essential introductory class. It teaches us about the fundamentals and allows us to get to know how computing devices work and communicate. There were many moments during the lectures where I had a moment of realization that things work much differently than I had anticipated. Prior to this the inner workings of a computer was a mystery to me, and I never thought about it twice. But now I have realized how much has to happen when I open a simple application.

Some of the new things I have learned

  • The different components of a computer
  • Binary logic and logic gates
  • Counting in binary and other counting systems
  • How the network works

What I have learned in Programming Basics:

In programming basics we learn about programming in JavaScript. JS seems like a more simple language to get started in programming rather than something like C++, and for me I am glad that that is the case, because as a first language I am able to understand it and follow the lectures at a steady pace. If it had been C++ it might have been much harder. I am getting to know the language more day by day, at the moment I am able to write a program that can run some sort of mathematical algorithm or a program that finds some kind of value based on some logical conditions. At the moment these small programs don't have much meaning, that they are not really doing anything practical for me. I would like to learn more and discover more tools and skills that allow me to develop something actually meaningful. Like a website for my portfolio or something that could be used by other people.

Some of the new things I have learned

  • Variables and data types
  • Conditional statements with one or multiple conditions
  • Different types of function declarations and return values
  • For and while loops
  • Arrays and the use of loops for arrays
